# NSVilla Frontend Build

This build contains the frontend overhaul for the NSVilla management system.

## Included
- Premium hospitality visual system
- Responsive application shell
- Redesigned authentication experience
- Live-data dashboard
- Reservations workstation
- Guest directory
- Room board
- Reception/front desk
- Restaurant POS
- Bar POS
- Pool services
- Payments ledger
- Reports/analytics
- Shared empty/loading/error states
- Shared design primitives and layout utilities
- Existing NSVilla property imagery/assets

## Data policy
No production business mock records were added. Empty installations remain genuinely empty and pages render empty states until real API data exists.

## Verification
A clean dependency install could not be completed in the build environment because the configured package registry returned HTTP 404 for the pinned Vite package. The source is therefore packaged without claiming a clean-machine compile verification.
