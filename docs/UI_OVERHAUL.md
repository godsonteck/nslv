# NSVilla UI Overhaul

This build establishes the refreshed NSVilla visual system across the shared application shell and reusable UI primitives.

## Visual direction
- Premium hospitality operations aesthetic
- Warm ivory surfaces, deep teal navigation, restrained brass accent
- Manrope headings + DM Sans body copy
- Soft borders and restrained shadows
- Dense but readable operational tables
- Consistent empty, loading, form, modal and drawer states
- Responsive navigation and global search affordance

## Updated foundation
- Header
- Sidebar/navigation
- Main application layout
- Page headers
- Metric cards
- Empty states
- Search inputs
- Form inputs
- Primary/secondary/accent buttons
- Global typography and surface tokens

## Important
The UI is connected to the existing real API architecture. No production mock records were added by this UI pass.
